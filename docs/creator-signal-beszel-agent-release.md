# Creator Signal Beszel Agent releases

`creator-signal/develop` carries Creator Signal automation derived from the immutable upstream `v0.18.7` source. `main` remains the unmodified upstream mirror; `creator-signal/main` is the reviewed downstream release source. Upstream refs are fetched separately and never overwritten by downstream automation.

Only `beszel-agent_linux_amd64.tar.gz` is eligible as the native host artifact. The release tag is explicit (`v0.18.7-cs.N`) and its release manifest follows `creator-signal.beszel-agent-release/v1`. It records upstream and downstream source identity, archive and extracted-binary SHA-256 values, size, SPDX SBOM/provenance references, and native Linux amd64/HUB v0.18.7 qualification references.

Forgejo runs the native Linux amd64 build and qualification. GitHub remains source, merge and publication authority. The GitHub publication workflow requires an exact Forgejo artifact URL, matching SHA-256 and the `FORGEJO_RELEASE_TOKEN` secret, then creates GitHub artifact attestations, publishes the assets, downloads them independently, compares the bytes and verifies provenance. It additionally signs the exact manifest bytes with the governed `BESZEL_RELEASE_ED25519_PRIVATE_KEY` and publishes `creator-signal-beszel-agent-release.signature.json`: Ed25519 base64 signature, manifest SHA-256, source revision and the SHA-256 of the trusted public key's SPKI DER.

Before publishing any release, the registered `Publish governed Beszel Agent release` workflow's `protect-release-source` operation applies `creator-signal/beszel-release-source-protection.json` through the governed `CREATOR_SIGNAL_REPOSITORY_ADMIN_TOKEN` secret. It is idempotent and re-reads the GitHub result to reject drift. The release workflows fail closed until this contract protects `creator-signal/main`.

After that signed source release exists, the same registered workflow's `publish-images` operation may be dispatched from the protected `creator-signal/main` source only. It verifies that the tag and signed agent manifest name the current exact source revision, then publishes multi-platform (`linux/amd64`, `linux/arm64`) Hub and Agent images to `ghcr.io/creator-signal/beszel-hub` and `ghcr.io/creator-signal/beszel-agent`. Images receive only the immutable release tag and exact source-SHA tag; mutable tags are forbidden. BuildKit emits SPDX SBOM and maximum provenance, high-or-higher vulnerability findings fail the run, and the release receives `creator-signal-beszel-images.json` containing the resolved image digests. No workflow registers an agent, changes a host, creates a Hub, or mutates an environment.
